Política de privacidad — Catholic Background

Catholic Background («la aplicación») está disponible para Windows, KDE Plasma y GNOME. Esta política explica qué datos se tratan cuando la usas.

Responsable

{{ opts.PRIVACY_CONTROLLER }}. Contacto: {{ opts.PRIVACY_CONTACT }}

Qué hace la aplicación

Para mostrar la imagen del día, la aplicación la pide periódicamente a este servidor. La petición solo contiene la fecha de hoy. La aplicación no pide, recoge ni envía tu nombre, tu correo, tu ubicación ni ningún otro dato personal, y no tiene cuentas ni inicio de sesión. Su configuración se queda en tu ordenador.

Qué registra este servidor

De cada petición, el servidor registra la dirección IP del ordenador que la hace, la fecha y la hora y la información técnica que envía la aplicación (como su versión). Según el RGPD, una dirección IP es un dato personal.

Para qué

1. Para detectar y corregir problemas del servicio (depuración y seguridad). 2. Para elaborar estadísticas de cuánta gente usa la aplicación. Las estadísticas son agregadas y no identifican a nadie. Base jurídica: nuestro interés legítimo en mantener, proteger y mejorar el servicio (artículo 6.1.f del RGPD).

Durante cuánto tiempo

Las direcciones IP completas se conservan como máximo {{ opts.ACCESS_LOG_DAYS }} días y después se borran. Las estadísticas se conservan sin direcciones IP (solo recuentos diarios) y pueden conservarse indefinidamente.

Con quién se comparten

Con nadie. Los datos no se venden ni se ceden a terceros y no se usan con fines publicitarios.

Tus derechos

Puedes solicitar el acceso a tus datos, su rectificación o supresión, la limitación de su tratamiento u oponerte a él escribiendo a {{ opts.PRIVACY_CONTACT }}. Como solo se guardan direcciones IP, puede que necesitemos que nos indiques tu dirección IP y las fechas en que usaste la aplicación. También puedes presentar una reclamación ante la Agencia Española de Protección de Datos (www.aepd.es). Si no quieres que se registre tu dirección IP, no uses la aplicación.

Cookies

Las aplicaciones (Windows, KDE, GNOME) no usan cookies. Este sitio web solo usa estas cookies, que se guardan únicamente para este sitio y no se usan con fines publicitarios ni para seguirte:

  • sessionid y csrftoken: necesarias para iniciar sesión y proteger los formularios. Solo para las personas que gestionan el contenido.
  • django_language: el idioma que eliges con el selector de idioma (un año). Si no eliges ninguno, no se guarda y se usa el idioma de tu navegador.
  • cookie_notice: recuerda que has leído el aviso sobre las cookies (un año).

Puedes borrarlas en cualquier momento desde tu navegador.

Cambios

Cualquier cambio en esta política se publicará en esta página.
